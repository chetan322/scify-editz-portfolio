PUBLISH FREE WITH GITHUB PAGES
1. Sign in/create a free account at https://github.com/
2. Click + (top right) > New repository.
3. Repository name: scify-editz-portfolio
4. Choose Public. Optionally tick Add a README file, then click Create repository.
5. In the repository, click Add file > Upload files.
6. Upload index.html (and optionally this README.txt).
7. Click Commit changes.
8. Open Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Select branch main and folder /(root), then click Save.
11. Wait a few minutes and refresh Pages to see the real published URL.
   It should resemble https://YOUR-USERNAME.github.io/scify-editz-portfolio/
   This is only an example until GitHub displays your actual URL.

UPDATE LATER
Open the repository, select index.html, use the pencil icon to edit, or upload a replacement. Commit the changes; Pages republishes automatically.
